# Platformeer
- This is the first game and finished project i have ever done.
- This is a project for Hackclub Nexus.
- In Platformeer, you play as a man collecting mushrooms while avoiding a spider chasing you and fields of fire that spawn when you collect a mushroom. The higher the difficulty, the more fire spawns when you collect a mushroom. Get the highest score possible, and have fun!
## How to play
- You run the game by pressing [the link.](https://piker215.github.io/Platformeer/)
- You move around using WASD or arrow keys in the main game.
- In menu's, you move around using AD or arrow keys and the spacebar.
- Buttons are activated by jumping into them.
- Abilities are activated by pressing the 4 key.
## Features
- Avoiding obstacles (chasing enemies and fires spawning)
- Gathering mushrooms
- Many difficulty levels
- Abilities, such as dashing
- Highscore system
- Coin system
- A store mechanic where you can buy abilities
- An interactable map through obstacles
